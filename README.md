# Автошкола «Мустанг»

Адаптивный сайт автошколы в Архангельске. Информация об обучении, автопарке и ценах, отзывы, галерея, документы и запись через форму.

![Главная страница](docs/images/preview.webp)

## Возможности

- Мобильная навигация, галерея со свайпами и просмотр документов.
- Форма записи с проверкой имени, телефона и согласия на обработку данных.
- Отправка заявок в сообщество VK через серверный PHP-обработчик.
- Защита формы от частых запросов и ботов, тайм-ауты отправки.
- Дата начала обучения из серверной конфигурации.
- Анимации с учётом prefers-reduced-motion и события Яндекс Метрики.

## Структура

| Каталог | Назначение |
| --- | --- |
| js/app.js | Запуск компонентов страницы |
| js/modules/ | Навигация, оформление, форма записи, аналитика, дата старта, слайдеры и документы |
| js/gallery.js | Класс галереи, лайтбокс, клавиатура и свайпы |
| styles/ | Базовые стили, компоненты и галерея |
| api/ | Проверка заявок, конфигурация и интеграция с VK |
| assets/ | Изображения, фотографии и документы |

Модули JavaScript используют явные import/export. Ключ VK читается на сервере из окружения и не попадает в браузер. Версия в URL импортов обновляется при изменении модулей из-за длительного кеширования статики на хостинге.

## Локальный запуск

Для всех функций нужен PHP 8+ с cURL. Скопируйте .env.example в .env. Для проверки интерфейса можно оставить ключ VK пустым, отправка заявки тогда вернёт сообщение о недоступности сервиса.

```sh
php -S 127.0.0.1:8080
```

Откройте http://127.0.0.1:8080. Встроенный сервер PHP не применяет .htaccess, API предусматривает обращение к файлам .php.

Для просмотра только интерфейса подойдёт статический сервер. Отправка заявок в таком режиме недоступна.

## Проверки и размещение

```sh
node --check js/app.js
php -l api/config.php
php -l api/send-lead.php
php -l api/get-start-date.php
```
