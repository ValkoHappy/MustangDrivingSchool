# Деплой MustangSuit на REG.RU и подключение заявок ВК

Проект рассчитан на обычный Apache/PHP-хостинг REG.RU. Node.js, Composer и база данных не требуются.

## 1. Обновление через Git

Репозиторий проекта: `https://github.com/ValkoHappy/MustangDrivingSchool.git`.
Git уже установлен на REG.RU, поэтому архивы и FTP для обновлений не нужны.

Однократно выполните в Shell-клиенте REG.RU. Команды сохранят текущий `.env` и сделают резервную копию старой папки:

```bash
set -e
SITE="$HOME/www/mustang-29.ru"
BACKUP="${SITE}.backup.$(date +%Y%m%d-%H%M%S)"
test -f "$SITE/.env"
mv "$SITE" "$BACKUP"
git clone https://github.com/ValkoHappy/MustangDrivingSchool.git "$SITE"
cp "$BACKUP/.env" "$SITE/.env"
chmod 600 "$SITE/.env"
cd "$SITE"
git log -1 --oneline
```

Если каталог сайта у REG.RU отличается, замените только значение `SITE` на путь из раздела «Сайты».

После этого каждое следующее обновление выполняется одной командой:

```bash
cd "$HOME/www/mustang-29.ru" && git pull --ff-only
```

Файл `.env` не входит в Git и не будет заменён при `git pull`. Не добавляйте его в репозиторий.

## 2. Конфигурация `.env`

Создайте `.env` в корне сайта:

```env
VK_ACCESS_TOKEN=токен_сообщества_ВК
VK_PEER_ID=2000000001
VK_API_VERSION=5.199
START_DATE=ОТКРЫТ
```

Токен должен принадлежать сообществу, иметь разрешение на отправку сообщений и не публиковаться в браузере, Git или логах.

`VK_PEER_ID` — идентификатор целевой беседы. Для групповой беседы обычно используется `2000000000 + ID беседы`.

В панели сообщества включите сообщения и добавьте сообщество в нужную беседу.

## 3. PHP и SSL

- Убедитесь, что для сайта включён PHP и расширение cURL.
- В панели REG.RU включите бесплатный SSL-сертификат Let's Encrypt.
- После включения SSL проверьте, что HTTP автоматически переходит на HTTPS.
- Если REG.RU использует другую версию PHP, выбирайте PHP 7.4+; код не требует сторонних пакетов.

## 4. Проверка после загрузки

1. Откройте `https://mustang-29.ru/` и проверьте главную страницу, мобильное меню, слайдеры и модальные окна.
2. Откройте `https://mustang-29.ru/education-info.html` и убедитесь, что в консоли браузера нет ошибок.
3. Проверьте дату: `https://mustang-29.ru/api/get-start-date` должен вернуть JSON.
4. Отправьте тестовую заявку из формы. Она должна появиться один раз в целевой беседе ВК.
5. Проверьте повторную отправку: после нескольких запросов API должен вернуть HTTP 429.
6. Убедитесь, что запросы к `/.env`, `/.git/` и `/api/test.php` не раскрывают содержимое.
7. Проверьте, что `https://mustang-29.ru/api/config.php` возвращает `403`, а `/privacy` перенаправляет на `/privacy.html`.
8. После обновления CSS или JavaScript увеличивайте версию `?v=...` в HTML: статика кэшируется браузером на длительный срок.

## 5. Типовые ошибки ВК

- `917` — сообщество не имеет доступа к беседе.
- `912` — отключён режим бота или сообщения сообщества.
- `922` — сообщество вышло из беседы.
- `984` — ограничение VK по спаму.

Техническая причина записывается в серверный журнал без токена, имени и телефона. Пользователь получает нейтральное сообщение и может связаться по телефону.

## 6. Безопасность

- Не храните реальные значения в `.env.example`.
- После миграции отзовите старый Telegram-токен, так как он ранее находился в коде и истории Git.
- Не включайте `display_errors` на боевом сайте.
- После изменения `.env` очистите OPcache или подождите обновления кэша PHP.
